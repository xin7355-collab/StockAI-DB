# 體檢與巡邏（audit）

⛔ **這支不做**：把誤報也「修」掉、為了變綠而放寬斷言、刪掉還沒驗證過的功能。
⛔ 採礦沒產出／JSON 停在舊日期 → 那是 **mining**，不是這支。

---

## ① 資料體檢（對象是 **gh-pages**，也就是手機真正讀到的那份）

```bash
python3 scripts/data_audit.py
```
六類：**A** 檔案存在/可解析/非空 ・**B** 新鮮度 ・**C** `*_error` 有值（含「值與 error 自相矛盾」）
・**D** 前後端對接欄名 ・**D2** 關鍵欄位缺漏 ・**D3** macro_cache 巢狀形狀對接。

🚨 **它抓不到「單一數字本身是錯的」** —— 檔案內部自洽時它看不出來
（台指期差 1,968 點那次是靠使用者截圖抓到的）→ **請使用者給外部對照截圖，那是最高價值的輸入**。

⚠️ 報「這個檔沒上 gh-pages」時，**先 grep 它是不是被刻意刪除／停用的**
（搜 `rm -f`、`= False`、「退役」「停用」）再決定補不補。

## ② 四支巡邏工具（⛔ 都 exit 0、⛔ 都不進四驗證）

```bash
node scripts/page_sweep.mjs          # ⭐ 最有效的一支,先跑這個(真實渲染後掃 innerText)
node scripts/card_inventory.mjs      # 砍卡之前先「量」每張卡的字數與有沒有下指令
node scripts/popup_audit.mjs         # 彈窗/通知/toast 一天總量與重疊
python3 scripts/check_lab_coverage.py # 探針登記表 vs 實測總表的漏收錄
```

`page_sweep` 找五類：① 缺值印給使用者（`跌破前低 --`）② 空頭卻叫人做多
③ 極端占比（1÷1 = 100%）④ 空殼卡 ⑤ **同一畫面兩張卡下相反的操作指令**。

🚨 **這幾支自己都曾經「安靜地量錯」**（沙箱連不到 Tailwind CDN → `.hidden` 沒生效；
只掃前 400 字 → 指令通常寫在最後；整頁被當成一張卡 → 跨卡偵測從沒觸發過）。
⭐ **工具報的數字，拿去做決策之前要先驗工具本身**：`node scripts/test_sweep_selfcheck.mjs`。

## ③ 多代理平行掃（找 bug 用，⛔ 不是每次體檢都要）

派 2~3 個 **scout** 代理（`.claude/agents/scout.md`），各自只掃一個範圍
（前端 `index.html` / 採礦 `*.py` / workflow `.github/workflows/`），
只回「確認的問題 + 行號 + 具體失敗情境 + CONFIRMED / SUSPICIOUS」。

---

## ④ 🚨 逐條人工驗真偽（**這一步不可跳，約 1/3 是誤報**）

對每一筆：
1. **讀原始碼**確認它真的會發生（⛔ 不憑推理、⛔ 不憑工具的話）
2. 想得出**具體失敗情境**（什麼輸入 → 什麼錯誤畫面）才算 CONFIRMED
3. 判定為誤報的，在 commit message 寫明「**已驗證非 bug**」留紀錄

⭐ 「有三處 `sys.exit(1)`」只是**可能性**，不是結論 —— 下「程式有問題」之前先確認它有沒有被跑到。

---

## ⑤ 修 → 注入驗證 → 分批

- **重現 → 診斷 → 對症 → 驗證** 四步驟，⛔ 不靠猜
- 每修好一個防呆，**注入一次已知缺陷確認它真的叫得出來**
  🚨 注入後先 `grep` 確認被改的是**你以為的那一段**（同一句話常在檔案裡出現三處）
  🚨 斷言的搜尋範圍要縮到**被改的那一塊**（否則會被頁面別處的同樣字串救活 = 假綠燈）
  🚨 每一輪之間 `find . -name __pycache__ -exec rm -rf {} +`
- **分 Batch commit**，每個 Batch 版本 +0.1，然後走 **ship**

## ⑥ 常見四種假綠燈（看到就知道不是程式的問題）

| 症狀 | 真因 |
|---|---|
| 測試綠、功能沒作用 | 測資的欄位格式跟真實產物不一樣（陷阱 #40）→ 先 `git show origin/gh-pages:data/x.json` 看一眼 |
| 本地過、雲端不過 | 本機是完整 clone / 有採礦產物 → 跟 git、網路、瀏覽器環境有關的一律不算本機測得過 |
| 永遠紅的測試 | 等於沒有測試 —— 會養成忽略的習慣，真壞那次也被當誤報 |
| 卡片直接不見、零錯誤訊息 | `catch (_) {}` 包住了自己寫的邏輯（`const` 又 `+=`，陷阱 #33） |
