# 📋 八個步驟

## ✅ 第 0 步:先去申請(要等,所以第一件事就做)

**⚠️ 你現在抓行情用的那把金鑰「不含」下單權限,兩者要分開申請。**

- [ ] 永豐金證券 → 申請 **API 下單權限**(線上或臨櫃,通常 1~3 個工作天)
- [ ] 下載**電子憑證** `.pfx`(⚠️ 通常一年到期,到期要重辦)
- [ ] 記下三樣東西:憑證檔路徑、憑證密碼、身分證字號

**怎麼確認做對了**:你手上有一個 `.pfx` 檔,而且知道它的密碼。

---

## ✅ 第 1 步:App 設定(2 分鐘)

- [ ] 散戶救星 → ⚙️ 設定中心 → 填「**帳戶總資金**」
      (沒填的話它算不出該買幾張、也算不出最多虧多少元)
- [ ] 同一頁 → 開「**自選股到價推播**」,並允許瀏覽器通知

**怎麼確認做對了**:選股頁的清單上開始出現「該買幾張 / 這筆最多虧多少元」。

---

## ✅ 第 2 步:純手動跑滿 1 個月(⛔ 最重要的一步,別跳)

**每天做三件事:**

1. **晚上**:產業作戰室 → 🎣 釣魚池 → 切到「**🏆 最強招式**」,或選股頁最上方的清單
2. **盤中 13:00~13:28**:收到「🚨 尾盤買點成立」推播 → **手動下單**
   - ⭐ 最貼近回測的做法:**13:25~13:30 掛單**(那段是收盤前集合競價,用**收盤價**撮合,
     而回測假設的進場價就是收盤價 → 理論上零滑價)
   - ⛔ **不是明天一開盤就買**(實測開盤買會把賺頭吃掉一半以上)
   - ⛔ **不是等它跌到那個價撿**(實測那是最糟的做法)
3. **成交後回 App**:「📌 追蹤中」→ 按「我買了」→ **填實際成交價**
   - ⛔ 不要填 App 算的那個價。填**真的成交價**,才量得出滑價
   - 出場後按「我出場了」→ **填實際賣價**

**出場規則(釣到的卡片上會直接算給你看):**
- 🛑 **停損**:取「進場 −5%」與「近 10 日最低」**較近**的那個
- 🚪 **出場**:收盤**跌破 5 日線**就走,最長抱 20 個交易日
- ⛔ **不設停利目標** —— 是「跌破就走」,不是「賺多少才賣」

**怎麼確認做對了**:累積至少 **10 筆**有填實際成交價的紀錄。

---

## ✅ 第 3 步:對帳(第 2 步滿 10 筆之後)

看 App 的「📒 你自己的實盤成績」:

| 看什麼 | 怎麼判讀 |
|---|---|
| 勝率 vs 回測 33% | 差 ±10pp 內算正常(樣本還小) |
| 每趟平均 vs 回測 | ⭐ **這個比勝率重要** |
| 平均滑價 | 超過 −0.5% 要找原因 |

**⛔ 差很多的話先找原因,別急著改策略:**
- **滑價**吃掉的 → 改掛單方式(往 13:25~13:30 靠)
- **沒守紀律**(該停損沒停) → 那是人的問題,**自動化才幫得上**
- **策略真的不行** → 那更不該自動化,**停在這裡**

**什麼情況要停**:滑價長期超過 −1%,或你發現自己根本做不到每天盯 13:00~13:28。

# 🅿️ 沒用到的錢停 0050(V79.4.9 起預設)

跟 App 決策台「🅿️ 沒買股票的錢停 0050」**同一個算法**:

- **該停多少** = `ACCOUNT_SIZE` ×(1 − `PARK_RESERVE_PCT`%)− 它自己買的 🔥 股票市值(⛔ 不含 👑 那筆錢、⛔ 不含你手動買的)
- **差距小於帳戶 2%** → 不動;**一天只買或只賣**(⛔ 不當沖 0050)
- **買**:一天最多 30 萬(第一次大約 3~4 天買滿);**真實模式一定先查交割戶現金**,買的金額⛔ 不超過現金(查不到那天不買)
- **賣**:只賣**它自己買的** 0050(狀態檔 `park.sh`;真實模式再跟永豐庫存比一次、取小的);
  今天有買 🔥 而現金不夠付 → 一定賣 0050 補(同一天賣 0050、買股票,交割款會相抵)
- 限價:買 = 現價 +1%、賣 = 現價 −1%(對到 ETF 跳動單位,⛔ 不超過漲跌停)—— 收盤競價時一定成交,除非鎖死
- ⚠️ `ACCOUNT_SIZE` 要填**你分給 🔥 + 🅿️ 的總資金**(股票 + 0050 + 現金),**跟 App 設定中心的「帳戶總資金」同一個數字**;
  股票 + 0050 超過它 1.1 倍 → 它會當成「數字過期了」,那天不動 0050

⛔ **第一次開之前**:先 `DRY_RUN=1` 跑一天,看它印的「該停多少 / 要買幾股 0050」跟 App 決策台那一行對不對得上。

### ⚠️ 真實帳戶第一次要先對一次交割款(V79.4.9 起,程式裡的 `PARK_LIVE_OK`)
永豐 API 回的「交割款」哪個方向是應付、哪個是應收,**官方文件沒寫**;程式靠它判斷「現金夠不夠」,看反了會以為錢比較多。所以:
- **真實帳戶**:停 0050 只**預覽**(印出「今天會買幾股」+ 永豐回的原始餘額 / 交割款),⛔ 不送 0050 的買單;模擬帳戶照常跑。
- **你要做的**:只有哪天要用真實帳戶時才需要(只跑模擬帳戶的話這段不用管)—— 那時照常跑一天(`DRY_RUN=1` 或真的跑都可以),把那天的 log 和永豐 App「交割款查詢」那一頁的截圖傳給 Claude → 對完正負號,下一版把 `PARK_LIVE_OK` 改成開(你 `git pull` 就好,⛔ 不用改設定)。
- ✅ V82.0.4 起 0050 的買賣單也跟股票一樣:送單出錯先問永豐今天的委託有沒有那一筆,確定沒有才重送一次(⛔ 同一筆賣兩次)。

### 🛡️ 它怎麼保護你的錢(V79.4.9)
- **湊交割款一定先做**:今天自動下單買了股票(🔥 / 👑)而現金不夠 → 先賣它自己買的 0050 補,⛔ 不會因為「帳戶總資金過期」、`PARK=0` 或沒設 `ACCOUNT_SIZE` 就跳過(只要手上還有它買的 0050)。
  0050 一直拿不到報價 → 下一分鐘再試;收盤前還不行(或程式 13:30 以後才啟動)→ 🚨 log 會寫清楚要你手動賣幾股(盤後定價 14:00~14:30 也賣得掉)。
- **送出 ≠ 成交**:真實帳戶的 0050 買單,隔天用永豐庫存的變化確認「真的買到幾股」才算它自己的(颱風假 / 被退單 → 一股都不算,⛔ 不會之後賣到你手動買的 0050);查不到庫存那天不買。
- **👑 的錢不動**:有開領頭羊(`LEADER=1`)時,`LEADER_ACCOUNT` 減掉 👑 持股成本那一段會留著,停 0050 / 湊交割款都不用它。
- **預覽不留痕跡**:`DRY_RUN=1` ⛔ 不寫狀態檔(之後同一天真的跑也不會以為做過了)。
- **模擬 / 真實分開記**:兩個模式用不同的狀態檔(見上表 `STATE_PATH`),模擬帳戶買的 0050 與股票在真實帳戶 ⛔ 不會被當成自己的去賣(第 5 步模擬 → 第 6 步真錢不用刪狀態檔)。
- **模擬帳戶接著用以前的紀錄**:V79.4.9 起模擬帳戶改用 `~/.stockai_auto_trade.sim.json`;更新後第一次跑模擬時那個檔還不存在 → 自動接著用以前那個檔(`~/.stockai_auto_trade.json`)的部位,以前模擬買的照常管、成績不會斷(log 印「📒 模擬帳戶改用自己的狀態檔…」;⛔ 舊檔一個字都不改,之後寫進新檔)。
- **真實帳戶第一次跑新版**:V79.4.9 以前兩個模式共用同一個檔 → 檔裡沒標「模擬 / 真實」的舊部位**一律當成以前模擬帳戶的紀錄**,搬到 `legacy`:⛔ 不自動賣、⛔ 不擋買,log 會用 🚨 列出來。⛔ 它不拿永豐庫存去猜是不是自己買的(庫存夠也可能是你手動買的同一檔 → 停損時會賣到你的)。
- **送單出錯 ⛔ 重複送**:整張 + 零股拆兩筆送,其中一筆出錯時只記「已經送出去的那段」(買 → 只記那幾股;賣 → 那幾股從紀錄扣掉),⛔ 不會把已送出的那段再送一次;🚨 log 會請你到永豐 App 確認。**賣單剩下沒送出的那段它會自己接著賣**(🔥 下一分鐘、👑 當天稍後;V82.0.4 起再送之前一定先問永豐有沒有收到,見下方「🧾 送單安全」)→ ⛔ 你不要自己手動賣剩下那段(不然會多賣)。
- **過了 13:30 ⛔ 不送 0050 的單**(收盤後送不進去):要湊交割款的話 🚨 寫清楚要你手動賣幾股。

## ④ 虧損安全鎖(預設關)
- `LOSS_LOCK_PCT=3` = 本月程式自己已實現的虧損 ≥ 本金 3% → 這個月不再買新的 🔥 / 👑(賣出、0050 照常;下個月自動解開)
- 已實現 = 程式自己的賣單成交均價 − 進場價,扣買賣手續費(0.1425%,⛔ 算折扣)和證交稅;只算收工對帳對到的那幾筆
- 本金 = `ACCOUNT_SIZE`(有開 👑 再加 `LEADER_ACCOUNT`);都沒設 → log 會寫「虧損安全鎖沒作用」
- ⚠️ 研究過「帳戶賠到一個程度就停手」6 種停法**全部少賺** → 這是**保險**、不是賺錢的方法,所以預設關

# 💰 為什麼是「等權」不是「風險法」(實測)

同樣每天 2 檔、**只改每筆買多少**(600 檔・13 個月・本金 100 萬):

| 部位大小 | 賺到的錢 | 中途最多賠 | 資金使用率 |
|---|---|---|---|
| ⭐ **等權(每筆本金 15%)** | **+1,718,529 元** | −9.31% | **92%** |
| 風險法 1%(單筆最多虧本金 1%) | +593,234 元 | −9.15% | **59%** |
| 🆚 0050 買進放著 | +832,500 元 | −15.9% | — |

⛔ **關鍵:風險法的回撤沒有比較小**(−9.15% vs −9.31%)→ **不是取捨,是單純比較差**。
少賺 112 萬**沒有換到任何安全性**。真因:停損寬的時候風險法只買很少張(甚至 0 張)
→ 資金長期只用到 59%,**四成的錢一直在睡覺**。

⚠️ 等權的代價:每筆的「風險 %」會浮動。程式會印出來,**超過本金 2% 會提醒你手動減量**。
