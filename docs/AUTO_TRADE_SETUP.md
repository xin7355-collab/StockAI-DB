## 🔐 最重要的一條規則

| | 跑在哪 | 為什麼 |

任何 workflow 都會讓 push 前檢查失敗。⛔ **不要為了「方便」繞過它。**

## 📅 五個階段(⛔ 別跳步)

### 階段 1️⃣ 純手動(現在 → 至少 1 個月)

**要設定的只有兩個:**
1. App → ⚙️ 設定 → 填「**帳戶總資金**」(它才算得出該買幾張、最多虧多少元)
2. App → ⚙️ 設定 → 開「**自選股到價推播**」+ 允許瀏覽器通知

**每天的流程:**
- 晚上:選股頁最上方看「🎯 明天要盯這幾檔」
- 想省事 → 按每列的「📋 條件單」複製,貼進永豐 App 的**智慧單 / 觸價委託**
  - ⚠️ 能設「**限定 13:00 之後才觸發**」就設上去。回測是「尾盤買」算的,
    條件單預設是「觸價就買」,可能 09:30 就成交 —— **那個時點沒測過**。
- 盤中 13:00~13:28:收到「🚨 尾盤買點成立」推播 → 手動下單
- **成交後回 App**,在「📌 追蹤中」按「我買了」→ **填實際成交價**
  - ⛔ 不要填 App 算的那個價。填真的成交價,才量得出滑價。
- 出場後按「我出場了」→ **填實際賣價**

**這階段的目標**:累積至少 **10 筆**,看「📒 你自己的實盤成績」跟回測差多少。

---

### 階段 2️⃣ 對帳(1 個月後)

看 App 的「📒 你自己的實盤成績」:

| 看什麼 | 怎麼判讀 |
|---|---|
| 勝率 vs 回測 33.2% | 差 ±10pp 內算正常(樣本還小) |
| 每趟平均 vs 回測 +1.96% | **這個比勝率重要** |
| 平均滑價 | 超過 −0.5% 要找原因(掛太急?量太小?) |

⛔ **差很多的話先找原因,別急著改策略**:
- 是**滑價**吃掉的?→ 掛單方式要調整
- 是**沒守紀律**(該停損沒停)?→ 那是人的問題,自動化才幫得上
- 是**策略真的不行**?→ 那更不該自動化

### 階段 3️⃣ DRY_RUN(只看不做,1 週)

```bash
pip install 'shioaji<1.7'

export SHIOAJI_API_KEY=你的key
export SHIOAJI_SECRET_KEY=你的secret
export ACCOUNT_SIZE=1000000        # 你的帳戶總資金
export MAX_LOTS_PER_TRADE=1        # 硬上限,先設 1

DRY_RUN=1 python3 auto_trade.py
```
**它只會印出「我現在會下什麼單」,完全不送出。**
把它印的跟 App 推播的比對 —— 應該要一樣。不一樣就是有 bug,⛔ 別往下走。

---

### 階段 4️⃣ 模擬單(1 個月)

```bash
python3 auto_trade.py          # 預設 simulation=True
```
永豐的模擬模式會真的送單到模擬環境。看它有沒有:
- 在對的時間(13:00~13:28)動作
- 買對檔數(不超過 `MAX_PICKS`)
- 同一檔不會重複下單

---

### 階段 5️⃣ 真實下單(小額起步)

**先去永豐申請**(抓行情的金鑰**不含**下單權限):
- API 下單權限
- 電子憑證 `.pfx`(通常一年到期,要記得換)

```bash
export SJ_CA_PATH=/你的路徑/Sinopac.pfx
export SJ_CA_PASSWD=憑證密碼
export SJ_PERSON_ID=你的身分證字號

LIVE=1 MAX_LOTS_PER_TRADE=1 MAX_AMT_PER_TRADE=50000 python3 auto_trade.py
```
⚠️ `MAX_AMT_PER_TRADE` 先設小(例如 5 萬)。跑順了再慢慢放大。

## 🎛️ 所有可調參數

| 環境變數 | 預設 | 說明 |
|---|---|---|
| `LIVE` | (無) | `=1` 才會真下單。⛔ 預設是模擬 |
| `DRY_RUN` | (無) | `=1` 只印不送單 |
| `ACCOUNT_SIZE` | 0 | 帳戶總資金(0 = 一律只買 1 張) |
| `RISK_PCT` | 1 | 單筆最多虧帳戶幾 % |
| `MAX_PICKS` | 3 | 一天最多買幾檔 |
| `MAX_LOTS_PER_TRADE` | 1 | 單筆張數硬上限 |
| `MAX_AMT_PER_TRADE` | 100000 | 單筆金額硬上限(元) |
| `EOD_FROM` / `EOD_TO` | 13 / 13 | 時窗小時(⛔ 別改成開盤) |
| `POLL_SEC` | 60 | 幾秒檢查一次 |
| `STATE_PATH` | `~/.stockai_auto_trade.json` | 防重複下單的狀態檔 |

## ⚠️ 已知限制(⛔ 別假裝不存在)

1. **本機沒有 App 那套偵測器** → `trig` 是 `null`(這招不是靠價位觸發)的那幾檔,
   `auto_trade.py` 會**直接跳過**。⛔ 不會用「差不多的條件」代替 —— 那是另一個沒驗證過的策略。
   那幾檔請看 App 推播手動處理。
2. **電腦要開著**。13:00~13:30 沒開機就不會下單。
3. **漲停買不到、量太小掛不進去** —— 回測沒有模擬這些。
4. **憑證會到期**(通常一年),到期後 `activate_ca` 會失敗。

## 🆘 出事怎麼辦

- **想立刻停**:`Ctrl+C`,或直接關掉程式。已送出的單要去永豐 App 自己刪。
- **懷疑重複下單**:看 `~/.stockai_auto_trade.json` 的 `done` 清單。
- **要重跑同一天**:刪掉那個狀態檔(⚠️ 會失去防重複保護)。
