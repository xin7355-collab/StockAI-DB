## 二、缺漏與落差(審查發現)

### 🔴 A. Parity Gap:前端有、Python 全市場掃描/回測沒有
前端偵測器多為 JS、逐檔、開圖才算;全市場 Python 只 port 一部分,`backtest.py` 只驗證自己較簡單的 `sig_*`。**最強訊號(回後買上漲、葛蘭碧、變盤線、背離)沒有全市場雷達、也沒有勝率驗證。**

### 🔴 B. 回測方法論落差
`backtest.py`/`walk_forward.py`/`paper_trade.py` 全用**固定 N 日報酬**(5/10/20/60)評估訊號,**不是朱式出場**(跌破5MA停利、破進場K低停損)。唯一做朱式逐根模擬的是 `radar_miner._chu_backtest`,且只套「回後買上漲」。

### 🔴 C. 逐字稿有、前後端都薄弱
1. 動態移動停損/停利升級(第 7、8 章:>7%取消停損、>20%加速、三均線分批)——只有靜態警示、回測沒模擬。
2. 進場前「上方空間≥10%」門檻(9-2)——只有季線壓力警示,非 gate。
3. 波段階段(底部/出生/主升/末升段)——用 pos52 近似,無明確末升段排除。
4. 淘汰選股法 13 條——散在各處,未系統化。
5. `worker.js` 停損 -4%/+8%,與朱式 -5%/+10% 不一致。

## 附錄:逐字稿規則萃取明細(第 1–11 章)

> 由多代理精讀 60 份逐字稿萃取,為 `strategy_sim.py` 的規格來源。

### 第 1 章 趨勢/轉折波
- 轉折波高低點:股價沿均線行進,**收盤**跌破均線 → 回看取含影線最高點為「頭」;收盤突破 → 取最低點為「底」。
- 多頭=頭頭高且底底高(H2>H1 且 L2>L1),六字全中;空頭反之;盤整=非多非空。
- 趨勢改變:回檔**收盤跌破前波低點**(底底低)當日即成立,約 90% 不再過前高。
- 回後買上漲(做多):維持頭頭高底底高 + 收>MA20 且月線向上 + 紅K實體漲幅≥2% + 量>昨 + 收突破MA5 且過昨高。

### 第 2 章 K線
- 實體分級:長(>6.5%)/中(3.5~6.5%)/小(<3.5%)紅黑。
- 強弱須與**昨收**比;`收>昨高`轉強、`收<昨低`轉弱(收盤價)。
- 橫盤:連≥3根未過前根高/未破前根低;長紅收盤突破區間高=做多。
- 變盤線(十字/紡錘,小實體):高檔=滯漲反轉、低檔=止跌;爆量反轉機率增。
- 三根組合:夜星(長紅+變盤+長黑,高檔轉跌)、晨星(反之);孤島(含缺口)最強。
- K線4+1元素:半值價=(H+L)/2=當日均成本;大量長紅隔日收<½=出貨/假突破。

### 第 3 章 均線 + 3-6 葛蘭碧
- 多頭排列:5>10>20>60 由上而下且上揚。
- 移動扣抵:明日收 > 扣抵值 → 均線上揚;< → 下彎(可預估轉向/黃金交叉時點)。
- 葛蘭碧八法(以20MA):買1突破、買2假跌破站回、買3回測支撐、買4負乖離>15%搶反彈;賣1-4對稱。

### 第 4 章 成交量
- 基準量=5日均量;攻擊量≥1.2~1.3×、爆量≥2×。
- 高檔爆量三類型:調節量(價縮量縮遇撐再攻)、換手量(3日內紅K過大量K高→再漲)、出貨量(不漲/跌破大量K低+頭頭低)。
- 起漲量價配合:回檔量縮→遇撐止跌→放量紅K過昨高=攻擊量;起漲大量紅K低點被跌破→轉出貨量。

### 第 5 章 五大選股法
- 六六大順:趨勢多頭 + 位置(出生/主升段) + 關鍵紅K + 四線多排站月線 + 攻擊量 + KD/MACD不背離。
- 特別報價:漲幅前100、剔除低量/<5元、套六六大順。
- 淘汰法 13 條(未打底/盤整不明/無量/漲幅≥100%/爆量連跌3天/未過大量壓力/高檔長黑/跌破下彎月線/破前低/漲一倍現頭頭低/指標背離/法人連賣/多重壓力)。
- 底部圖形:未破前低 + 底部爆量 + 型態(反轉底/均線糾結/爆量突破月線/過前高/頭肩底圓弧底)。
- 5MA飆股:第一波強勢連紅四線多排→第二波回後買上漲進場→沿5MA抱、跌破停利。

### 第 6 章 進場位置
- 最可程式化三項:回後買上漲、盤整突破、K線橫盤突破——核心一致(趨勢確認→定壓力線→紅K帶量突破/站5MA→停損進場K低或跌破5MA)。
- 型態、切線、軌道線類需圖形辨識,較難純量化。

### 第 7–9 章 停損/停利/戰法
- 停損:進場K低(短)/前波低(長)/跌破5MA/固定-5%(最常用,3~10%不超10%)。
- 動態:獲利+7%取消停損改停利;+20%改守更嚴;跌破5MA停利;高檔爆量長黑上影加速停利。
- 停利目標:短線+10%;進場前算上方空間(前高/季線/切線/缺口)≥10%才進。
- 均線戰法:短線守5MA、長線守20MA;三均線分批3張(跌破5/10/20各賣1張)。
- K線轉折戰法(強勢股):每日守前一日低點,收盤跌破即出,不看均線。

### 第 10–11 章 心理/贏家
汰弱換強、集中2~5檔、不攤平不逆勢、大賺小賠靠紀律、進場前先決定做長或短且不中途改。
