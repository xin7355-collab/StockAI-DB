散戶實戰時間軸 — 跟著走、不踩雷

🌅 盤前 08:30 ~ 09:00
觀察美股前導 + 大盤信用水位 + 全球風向。
  • 08:30 大盤信用解碼：融資餘額 > 3200 億 → ⚠️ 散戶高槓桿警惕
  • 08:30 ADR：SOX / NVDA / TSM ADR → 預判半導體與台積電開盤方向
  • 08:45 台指期：夜盤台指期/小台未平倉,判斷主力布局多空
  • 08:45 國際資金溫度：DXY、美債 2Y、CNN 恐懼貪婪指數（>75 過熱、<25 極恐）
🚀 開盤 09:00 ~ 09:30
觀測量能天條、板塊輪動、期現背離。
  • 09:05 預估量能天條：當日預估量低於昨量 → 縮量盤,不追高
  • 板塊輪動矩陣：「9 大資金板塊」看哪些燈綠（熱錢進場）→ 主流挑龍頭
  • 期現背離預警：台指期 vs 加權指數背離 → 主力對盤後預判
📡 盤中 09:30 ~ 13:00 ｜ 雷達兵法鎖定與紀律控管
「首席戰略雷達矩陣」動態掃描全市場 1967 檔個股,依三大策略嚴格執行紀律。
  • 🏎️ 渣男賽車（動能爆發）
    演算法：個股成交額 > 5 億、近 5 日內單日噴發 7%+、收盤站上 5 日線
    紀律：專賺快錢！盤中一旦跌破 5 日線 必須無情停利,嚴防主力高檔出貨
  • 🐢 烏龜過河（波段平穩）
    演算法：剛站上 月線、法人連續 3 日 買超、量能同步放大
    紀律：沿 月線 操作,不破不出場！大資金月線上分批金字塔長抱,等波段利潤擴大
  • 🎯 狙擊手（籌碼集中）
    演算法：股價貼著 月線 盤整、前三大主力買盤集中度 >= 30%
    紀律：月線盤整期精準現股狙擊試單。天條:主力一連賣我們就跑！
    🥣 碗型底頸線回測:底部突破後回測 頸線,若遇「大盤回檔但量能極度萎縮」且頸線有守 → 絕佳買點(冠軍操盤手實戰常用)
    📈 上升軌道下緣:業績成長股沿 上升軌道 走揚,回測 軌道下緣 收長下影線時 → 精準狙擊
🔪 崩盤接刀與高乖離防呆 ｜ 風控天條
大跌時的鐵律,違反即賠光半年波段成果。
  • 大跌時嚴禁介入 創高且乖離過大 的標的,極易開盤跌停被關
  • 高檔若出現 放量大黑K → 必須無情停利,當天賣不到明天跳空缺口認賠
  • 前期飆股遇連續跌停 → 絕對禁止於月線接刀!必須耐心等待 季線 (60MA) 方可重新建倉
💰 資金配置守則 ｜ 活著比賺錢重要
散戶畢業最大主因是「重押單一檔 + 滿融資」。守住這三條,大跌也不會畢業。
  • 單檔上限 ≤ 10% 本金:再看好也不重押,一檔黑天鵝最多傷 10%
  • 總槓桿 ≤ 150%(現股+融資):嚴禁全額融資,留現金才有底牌加碼
  • 黑天鵝警報亮起 → 總持股自動降至 50% 以下,寧可少賺不要重傷
  • 分批進場:同一檔分 3 批進場,跌破防守線只認賠該批,不攤平凹單
🎯 尾盤 13:20 ~ 13:30
日 K 朱家泓 SOP — 收盤定生死。
  • 跌破 5MA → 短線停利出場（夏季趨勢股紀律）
  • 守穩月線 → 波段續抱（多頭持股紀律）
  • 跌破月線 → 🟠 減碼觀望（剩 1/3 倉）
  • 跌破月線 + 大黑K/島狀反轉 → 🔴 全部出場
  • 13:25 集合撮合防線：尾盤 5 分鐘觀察大單湧入方向,確認收盤是否站穩防守均線
🌙 盤後 13:40 ~ 14:30 ｜ 盤後交易與深夜期貨避險金盾
現貨收盤後的延伸戰術,供非即時追高者優雅建倉,並為持倉構築機構級全時風控防空洞。
  • 💰 13:40 ~ 14:30 ｜ 盤後定價交易
    針對尾盤 13:30 確認收盤站穩關鍵支撐、符合朱家泓右下角建倉訊號的標的,於 14:30 統一搓合,用今日最公道的「最終收盤價」進行現股買進。
  • 🧱 13:40 ~ 14:30 ｜ 零股盤後交易
    針對高價頂級權值股（如台積電）,利用盤後零股通道進行「金字塔逢低分批低接」,執行無壓力長線存股。
  • 等系統每日 16:30 採礦更新（三大法人 / 主力分點 / 雷達）後覆盤,用雷達兵法掃出明日觀察清單、加入 ⭐ 自選。
🦅 夜盤 15:00 ~ 次日 05:00 ｜ 台指期貨夜盤避險
夜盤期貨避險,守住隔日開盤跳空風險。
  • 台指期夜盤：15:00 開盤,反映美股盤前與歐股,可作為當沖隔日的多空風向球
  • VIX 期貨：恐慌指數飆升 → 隔日台股大概率跳空低開,庫存先設止損
  • 重大持倉者：夜盤可考慮買入賣權避險（保險概念,不必全倉,5~10% 部位即可）
  • 📉 選擇權 Put (買進賣權):利用高槓桿做資金保護傘,大跌時報酬倍數放大,小額即可保大部位
  • 🏆 冠軍心法:避險單若遇大跌趨勢確立,切勿因微小獲利太早平倉,以免錯失倍數級保護效果!
🚨 妖股處置神器(關禁閉風控雷達)
專治「🏎️ 渣男賽車」!提早看穿飆股生死線,拒絕喪失流動性。
  • 處置四大天條:連 3 條款、連 5 條款、短期太頻繁(10 中 6)、長期常態犯(30 中 12)
  • 盯盤秘訣:留意「價格門檻」與「量價門檻」,若盤中觸發實質達標(量價雙破),明日必關!
  • 聽牌狀態解碼:若顯示為「必關股」或「聽牌中」,短線操作者應趁拉高時無情停利,嚴禁新建倉!
⚔️ 首席雙刀戰法(處置股進階收割術)
  • 🗡️ 進攻刀(關前末日狂歡):當股票最快再 1 天被關,主力常作最後拉抬。若資金狂熱,可極短線當沖或隔日沖。紀律天條:收盤前 13:25 無論盈虧必須手起刀落全數清倉,絕不留單過夜!
  • 🛡️ 狙擊刀(獄中量縮撿屍):當股票已 🚨 處置中,若跌至黃金支撐(如月線)且主力籌碼集中度仍 > 30%,此為經典「關廁所洗盤」,應冷血分批低接,等待出獄噴發。
